# Мітки

Трекер задач, де кожна задача отримує результат: ✓ виконано, ◐ частково або ✗ не вдалося. Один HTML-файл, без залежностей і збірки.

## Можливості

- Задачі з результатом: кнопки ✓, ◐ і ✗ на кожній активній задачі; повернення в активні (↺) і видалення (🗑) з можливістю відмінити.
- Кольорові мітки: створення через «＋ мітка», вибір мітки для нової задачі, фільтрація за міткою, видалення мітки (задачі лишаються без мітки).
- Вкладки «Активні», «✓ Виконані», «◐ Частково», «✗ Не вдалося» та «Усі»; пошук за назвою.
- Теплокарта активності у стилі GitHub за останній рік або за обраний рік, з підказкою при наведенні.
- Статистика: кількість позначок, виконано, успішність (частково враховується як половина), поточна серія днів і рекорд серії.
- Розбивка успішності за мітками.
- Аніме-пейзаж у трьох варіантах доби: день, захід і ніч (перемикач ☀️).
- Опціональні пелюстки, які падають (перемикач 🍃; вимикаються також при `prefers-reduced-motion`).
- Власний фон із картинки з комп’ютера (🖼); картинка стискається до 1920 пікселів.
- Експорт і імпорт даних у JSON (⬇ Експорт, ⬆ Імпорт).
- Синхронізація між вкладками одного браузера: зміни в одній вкладці з’являються в інших.

## Запуск

Найпростіше: відкрити `index.html` у браузері напряму.

Або запустити локальний сервер з папки проєкту:

```sh
python3 -m http.server 8787 --bind 127.0.0.1
```

і відкрити у браузері адресу http://localhost:8787.

### Як програма для macOS

У папці `app/` лежить нативна оболонка: одне вікно на системному WebKit, яке показує `index.html` із бандла — без браузера й без сервера.

```sh
sh app/build.sh
```

Скрипт збирає `Мітки.app` (близько 800 КБ) і кладе в `~/Applications`. Потрібні лише Command Line Tools (`xcode-select --install`). Після зміни `index.html` запусти збірку ще раз. Дані програми зберігаються окремо від даних у браузері.

## Керування

- `/` — перевести фокус у поле нової задачі (не працює, коли фокус уже в полі вводу).
- `Enter` у полі нової задачі — додати задачу.
- Подвійний клік по назві задачі — редагувати її; `Enter` зберігає, `Escape` скасовує.
- `Enter` у полі нової мітки — створити мітку; `Escape` — скасувати.
- Клік по імені профілю — змінити його; `Enter` зберігає.
- Після позначення, повернення або видалення внизу з’являється повідомлення з кнопкою «Скасувати» (або «Повернути» для видалення), яке діє кілька секунд.

## Дані та резервні копії

- Усі дані зберігаються в `localStorage` браузера. Вони прив’язані до конкретного браузера і адреси, з якої відкрито застосунок: `file://` або `localhost:8787` — це різні сховища.
- Дані не надсилаються на жоден сервер і не залежать від мережі.
- Щоб перенести дані або зробити копію, скористайтеся кнопкою «⬇ Експорт», яка зберігає файл `mitky-РРРР-ММ-ДД.json`.
- «⬆ Імпорт» замінює поточні дані даними з файлу; перед заміною буде запит підтвердження.
- Якщо сховище браузера переповнене, застосунок про це повідомить. Фон зберігається окремо і може не влізти у сховище.

## Технології

- Один файл `index.html`: HTML, CSS і JavaScript без бібліотек і збірки.
- Пейзаж — один статичний SVG без зовнішніх зображень; мережа не використовується.
- Анімація пелюсток оновлює лише `transform`, тож навантаження на процесор і пам’ять мінімальне.
